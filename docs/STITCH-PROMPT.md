# Stitch master brief

Create SabiWork, a responsive Nigerian artisan marketplace. Tagline: Skilled hands. Trusted work. Roles: customer, artisan, admin. Use all the supplied references as a combined moodboard: expressive photographed service landing pages, clear mobile discovery and multi-step booking/payment, confident green/neutral service cards, and restrained sidebar workspaces. No single reference dominates. Make an original coherent system.

Use the design contract in DESIGN.md. Approved light sky blue #38A8E8, pale blue #EFF8FF, white and dark slate text with accessible darker blue actions; realistic Nigerian artisan imagery, no copied logos, invented traction, live insurance claims or fake discounts. Skills include plumbing, electrical, tailoring, carpentry, painting and cleaning. Benin City example area. Prices in NGN/naira, dates WAT. Shared example: customer Ada, artisan Osaze, sink repair quote NGN 30,000, deposit NGN 10,000, balance NGN 20,000. Test-mode payments only; do not claim escrow guarantees.

First establish components and create homepage, results, artisan profile, job request, quote comparison, milestone checkout and artisan dashboard at 390x844, 768x1024 and 1440x1024. Mobile must be designed explicitly with compact navigation and sheets; tablet has adaptive columns; desktop has public navigation or workspace sidebar. No stretched mobile layouts.

Then complete all S01-S48 in DESIGN.md across all three sizes, in reviewable batches. Required flow: find artisan -> profile -> request -> quote -> accept -> test deposit -> progress -> sign-off -> test balance -> review. Include dispute/admin, verification, availability, earnings, training and all accounts screens. Separate default, loading, empty, error, partial, success and permission states where relevant. Include persistent field labels, focus states, 44px touch targets and accessible contrast.

Keep all screens editable and clearly named for Figma handoff. Do not add live chat, maps, wallets, subscriptions, discount shopping or production escrow. Give primary tasks prominence over promotional blocks. See DESIGN.md for complete screen list, ownership, state triggers and handoff structure.

Keep the existing project and edit the original fan-of-artisan-portraits homepage in place. Do not create a different homepage or another project/file. Icon-only logo, separate editable SabiWork text, consistent role navigation, nonshrinking buttons and unbroken labels.
